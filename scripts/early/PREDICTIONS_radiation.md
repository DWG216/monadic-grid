# Pre-registered before running radiation.py (2026-11-07)
Correction to previous prediction: "timelike paths of the same length" is ill-posed (null length = 0), and a single plane wave
cannot discriminate (any crossing path samples its whole profile). Reformulated:
Setting: linearized gravity, K=8 waves from different directions in a plane, compactly supported (non-analytic) pulses.
Each wave k has hand+ profile A_k(u) and hand- profile B_k(u); real spacetime <=> B_k = conj(A_k) for every k.
Question: which data sets, inside one causal diamond, force B_k = conj(A_k) for ALL k (full rank)?
Q1: a single curve -- static worldline, moving timelike geodesic, or single light ray -- is NOT enough (sees only sums over directions).
Q2: a 2D surface -- the diamond's light-cone boundary OR a spacelike slice -- IS enough.
Consequence if Q1, Q2 hold: sufficiency does not single out light. Light's distinctive role (free, unconstrained data with the
two hands cleanly separated) is a different property, not tested here.
Tier: counting consequence (largely determined by dimension), not a deep test.
