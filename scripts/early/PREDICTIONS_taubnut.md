# Pre-registered before running taubnut.py (2026-11-07)
Setting: complexified Kerr-Taub-NUT, parameters m, n, a complex. The two curvature hands:
  hand +  Psi2  = -(m + i n)/(r - i(n + a cos th))^3
  hand -  Psi2~ = -(m - i n)/(r + i(n + a cos th))^3
Real Lorentzian spacetime <=> m, n, a real. Conjugate match on a set S: Psi2~ = conj(Psi2) at real (r, th) in S.
P1 (light suffices): matching along ONE principal null ray (fixed generic th, r sweeping) forces Im m = Im n = Im a = 0. [expected; largely analyticity]
P2: a ray in the equatorial plane (cos th = 0) leaves Im a undetermined.
P3 (control): matching at a single event does NOT force reality.
P4 (is light special?): a radial timelike curve at fixed th (r sweeping) does exactly as well as P1 -> in this setting light is sufficient but NOT singled out.
P5 (googly, identity): a one-handed (self-dual, m = i n) member passes the match only if flat (m = n = 0).
Tier labels: P1, P2, P5 = consequences of analyticity/known structure; P3, P4 = real tests of how much and what kind of data is needed.
Strong conjecture ("only light can glue the hands") FAILS here if P4 holds; weak conjecture ("light suffices") holds if P1 holds.
