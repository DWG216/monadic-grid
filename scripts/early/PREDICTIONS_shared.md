# Pre-registered before running shared.py (2026-11-13). Label: toy model (math).
Question: can distinct monads share one spacetime, i.e. read each other's holographic records? Model: an image (a record) is written by monad A with
its reference wave (a coherent spectrum: a set of 40 wavevectors with phases) and read by monad B with B's spectrum. Fidelity = correlation of the
reconstructed image with the original.
S1 [real test]: with shared wavevectors at agreed phases, fidelity rises in proportion to the overlap fraction f (about f; 0 at f = 0, ~1 at f = 1).
S2 [control]: same shared wavevectors but independent random phases: fidelity stays small (about f / sqrt(shared count)), far below S1.
S3 [many monads]: 20 monads, each = a common core of c phase-agreed wavevectors + private ones. Mean cross-reading fidelity tracks c/40;
   with c = 0 it is near 0, so no shared record (no common spacetime) without a phase-agreed core.
Interpretation fixed in advance: sharing one spacetime requires common frequencies with agreed phases (pre-established harmony); shared
frequencies alone are not enough.

S1 PASS: agreed phases: 0.21, 0.28, 0.53, 0.77, 1.01 for f = 0, 0.25, 0.5, 0.75, 1 (the metric has a noise floor near 0.2 from cross terms).
S2 PASS: random phases on the shared waves: 0.18-0.25 at every f, at the noise floor.
S3 PARTIAL: 20 monads: 0.18 (c = 0, floor), 0.32, 0.52, 0.53, 0.98 (c = 40). Rises with the core but c = 20 and 30 tie (one random core per c; noisy).
Verdict: in this toy model, monads read each other's records only through common frequencies with agreed phases; shared frequencies with independent
phases give nothing above the floor. Caveat: the outcome is close to built into linear superposition; it states what "sharing one spacetime" requires
(phase agreement), it does not show that monads achieve it.
