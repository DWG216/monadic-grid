# t22 interaction term on a light ray (pre-registered 2026-11-22 17:56)
Sachs optical equations (NP): D rho = rho^2 + sigma sigmabar + Phi00, D sigma = (rho + rhobar) sigma + Psi0, from a vertex (rho ~ -1/lam). Constant sources.
S1 [M] Psi0 only: sigma/lam -> Psi0/3; (rho + 1/lam)/lam^3 -> |Psi0|^2/45; area deficit -ln(A/lam^2)/lam^4 -> |Psi0|^2/90 (rel. err < 1e-3 at small lam).
S2 [M] Phi00 only (positive control, Ricci): area deficit -ln(A/lam^2)/lam^2 -> Phi00/3: Ricci at order 2, Weyl only at order 4.
S3 [M] Bilinearity: deficit coefficient scales as |Psi0|^2 (doubling Psi0 quadruples it; phase of Psi0 irrelevant).
C0 null: Psi0 = Phi00 = 0 gives zero deficit (< 1e-12).
