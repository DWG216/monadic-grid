# t60 three generations: E8 (mod 5) contains E6 (mod 3) x SU(3) with matter in triplets (pre-registered 2026-11-23, before run)
Start: our McKay graph of 2I on the hand pair V (t55). Nodes = irreps of 2I; affine E8.
G0 V's neighbours are the trivial node (vacuum) and one 3-dim node M; V x V = 1 + M (M = the meeting triplet).
G1 Deleting M from the affine E8 graph leaves two pieces: {vacuum, V} (A2, Cartan det 3) and six nodes (E6, Cartan det 3).
G2 Finite E8 (affine minus vacuum): Weyl orbit of a simple root = 240 roots.
G3 Grading the 240 roots by the coefficient c of M's simple root: c = 0 gives 72 (E6 roots), c = +-3 gives 6 (A2 roots), c = 1 mod 3 gives 81, c = 2 mod 3 gives 81.
G4 The 81 roots with c = 1 mod 3 project onto the E6 directions as 27 distinct weights, each 3 times (27 x 3 = one E6 27 in a triplet of the family SU(3)); same for c = 2 mod 3 (27-bar x 3-bar).
G5 The 27 projected weights form one orbit under the E6 reflections.
Control: grading by the 2-dim node next to the branch node does not give the 78 + 81 + 81 split.
