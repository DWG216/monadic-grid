# t55 open problems 1-4 (pre-registered 2026-11-23, before run)
## 1 Hidden 3 dimensions = the other hand (icosahedral cut-and-project)
Six icosahedral axes a1..a6 in Z[phi]^3 (E_par, 3x6); E_perp = same with phi -> psi = 1 - phi.
1a E_par E_perp^T = 0 (visible and hidden spaces orthogonal in R^6). 1b E_par E_par^T and E_perp E_perp^T are multiples of I3.
1c The 6x6 map M with E_par M = phi E_par and E_perp M = psi E_perp has rational entries with denominator dividing 2; M or M^3 is an integer matrix (a lattice symmetry: the inflation).
1d 1D case: Q on Z^2 has eigenvalues phi, psi; det Q = phi psi = -1.
## 2 McKay graphs from representations (not counts)
Groups built as unit quaternions in SU(2); characters from class algebra; A_ij = <chi_V chi_i, chi_j>, V = the 2-dim rep.
2a Q8: 5 nodes, one node of degree 4, four leaves (affine D4). 2b 2T (24): 7 nodes, tree, one branch node, three arms of 2 (affine E6), dims {1,1,1,2,2,2,3}.
2c 2I (120): 9 nodes, tree, one branch node, arms of 1, 2, 5 (affine E8), dims {1,2,3,4,5,6,4,2,3}. 2d A d = 2 d in each case.
2e Element-order profiles: SL(2,3) (t53) = 2T, SL(2,5) (t54) = 2I.
## 3 The groups acting on the record
3a In F9 = F3(phi): Frobenius x -> x^3 sends phi to psi = 1 - phi (hand swap) and i = phi^2 to -i (complex conjugation).
3b det of the Fibonacci step to the n = norm N(phi^n) = (-1)^n = Cassini F(n-1)F(n+1) - F(n)^2, n = 1..60.
3c Golden powers with det 1 are exactly {1, i, -1, -i} (the circle face).
3d In SU(2) acting on the hand pair (z+, z-): i = diag(i, -i) counter-rotates the hands; j = [[0,-1],[1,0]] swaps them, (z+, z-) -> (-z-, z+); j^2 = -1 (720 degree rule).
## 4 The 3-adic tower
4a |<Q^2, U> mod 3^k| = 24 * 27^(k-1) (all of SL(2, Z/3^k)) for k = 1, 2, 3, 4. 4b |<Q, U> mod 3^k| = twice that.
4c Q mod 81 has order 216 but generates a cyclic group, so it is not the Hessian group (non-abelian): the 216 match is a count.
