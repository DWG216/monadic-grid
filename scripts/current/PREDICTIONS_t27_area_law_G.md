Srednicki (1993) radial lattice for a free scalar (coupled oscillators = sinusoids), N = 60 sites, partial waves l = 0..lmax, entropy of the inner n sites (R = n + 1/2), summed with weight (2l+1).
A1 [M] S(R) fits c R^2 with c in [0.27, 0.33] (Srednicki: 0.30), for n = 6..24.
A2 [M] Area, not volume: a fit c3 R^3 + c0 has larger residual than c2 R^2 + c0 (ratio > 3).
A3 [M] Convergence: S changes by < 1% from lmax = 2000 to lmax = 4000 at n = 24.
Then (Jacobson 1995, delta Q = T dS on local light cones; Sakharov's induced gravity): G = 1/(4 eta) with eta = c/(4 pi) per a^2 and one species, i.e. G = pi/c a^2 per species, G_N = pi/(N_species c) a^2. Reported, not a test.
