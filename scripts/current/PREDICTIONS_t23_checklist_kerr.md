# t23 checklist items 1-6 on exact nonlinear solutions (pre-registered 2026-11-22 18:05)
Exact vacuum with both hands: Kerr (M=1, a=0.6), Kerr-Schild Cartesian form, signature (-+++). Control: Kerr-Newman (Q=0.5, electrovac).
Curvature by nested 4th-order central differences in long double; Weyl tensor C (Ricci parts removed); Bel-Robinson T = C C + *C *C; orthonormal frame by Gram-Schmidt.
Points: (4,1,1.5), (0,5,-2), (3,-3,3) at t=0.
K1 [M] Bilinear: T(k,k,k,k) / |Psi0(k)|^2 is one constant over 100 random null k per point and across points (CV < 1e-6), Psi0 = C(k,m,k,m). Single-hand parts C+- = (C -+ i*C)/2 give T(k,k,k,k) = 0 (rel. < 1e-8).
K2 [M] Forced form: argued by spinor type (4,4) (§97); checked here only that T is totally symmetric and trace-free (< 1e-8 rel).
K3 [M] Positivity: T(u,v,w,x) >= -1e-10 * max|T| for 20,000 random future causal quadruples per point (Kerr). Null comparison (reported, no threshold): C C alone on the same quadruples.
K4 [M] Conservation on the exact nonlinear geometry: max|nabla^a T_abcd| / (max|T| / r) < 1e-4 at every Kerr point; Kerr-Newman control > 1e-2 at every point.
K5 [M] Order 4 on the cone: covered by t22 (Sachs) and §85 (Kerr cones, measured); not re-run.
K6 [M] Helicity 0: under m -> e^{i th} m, Psi0 -> e^{2 i th} Psi0 (phase check < 1e-10) while T(k,k,k,k) is unchanged.
