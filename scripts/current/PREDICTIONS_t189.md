# PREDICTIONS t189: the generation chord's meeting share, three sectors

Registered 2026-11-28, committed before t189_mass_shares.py is written or run.

Disclosure, in full. The hypothesis was found post hoc on the t99 numbers (Q_u = 0.889 ± 0.004, Q_d = 0.743 ± 0.017): the three Koide quotients sit near 2/3, 3/4, 8/9, which is Q = (n+1)²/(6n) for n = 1, 2, 3, equivalently a chord amplitude c² = n + 1/n. No ground reason for n has been found; this registration tests whether the pattern survives a newer, independent extraction of the running masses, and measures how distinctive a simple-fraction match is. The new data (Huang and Zhou, arXiv:2009.04851, Table 2, full SM at μ = M_Z) were read before this file was written; Q was not computed from them. They share lattice and PDG inputs with the t99 set, so they are an update, not a fully independent sample. Q is dominated by the two heavy members of each sector, so this is mainly a test of m_c/m_t and m_s/m_b.

Data (MS-bar, μ = M_Z, as printed): m_t 168.26(75) GeV, m_b 2.839(26) GeV, m_c 0.620(17) GeV, m_s 53.16(4.61) MeV, m_d 2.67(19) MeV, m_u 1.23(21) MeV. Errors treated as independent Gaussians, 10⁵ Monte Carlo draws, negative draws rejected.

Grid reading [S]: Q = Σm/(Σ√m)² is the diagonal (meeting) share of the generation chord's record, Q = 1/(1 + cross/diag), with cross/diag = 1/2 for leptons.

P1 [M]: Q_u lies within 2σ of 8/9.
P2 [M]: Q_d lies within 2σ of 3/4.
P3 [control]: for each of Q_u and Q_d, the 2σ window contains exactly one fraction p/q with q ≤ 9, and it is the predicted one. If a window holds several, a simple-fraction match there carries little weight.
Consequence fixed now: P1–P3 all pass → the pattern stands as an observation worth a ground reason for n; it does not enter the record as derived until n is traced to the ground. Any fail → the pattern is recorded as not surviving, and the quark amplitudes stay open as in t99.
